Modelo base de referencia

El PDF nombra estas tablas: Estudiantes, Autores, Tipos, Libros y Prestamos. Como el diagrama queda embebido como imagen, la guía usa estos nombres de columnas coherentes con los enunciados. Si tu script del profesor tiene algún nombre distinto, cambiá el alias/columna, pero la lógica de cada consulta es la misma.
